# Phase 27 — BAU & Continuous Improvement practice pack

Use these templates to operate and improve the ApexPlan training service after implementation. Replace sample rows with controlled training evidence; do not use client or production-sensitive data.

1. `bau-service-charter.csv` — establish service scope, decisions, ownership, coverage, and escalation.
2. `service-health-scorecard.csv` — measure technical, process, control, experience, and sustainability outcomes.
3. `improvement-backlog.csv` — define, assess, prioritize, trace, and govern changes.
4. `benefits-roadmap.csv` — connect adoption, benefits, releases, owners, and the funded roadmap.

The learner should be able to explain not only what to improve, but why, how it will be changed safely, how adoption will be supported, and how value will be evidenced.
