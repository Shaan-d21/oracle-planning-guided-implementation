# Phase 25 — Go-Live practice pack

Use these templates to activate the authorized ApexPlan production scope, prove the first live cycle, control incidents, and transfer a known operating state to Hypercare.

## Files

- `go-live-activation-runbook.csv` — user, integration, schedule, business-cycle, reporting, and communication activation waves.
- `first-cycle-control.csv` — source-to-user-to-reporting execution and full-precision reconciliation.
- `incident-log.csv` — production impact, containment, recovery boundary, decisions, fixes, and communications.
- `hypercare-handoff.csv` — inventory, open ownership, monitoring, cadence, escalation, and acceptance.

The `01`–`09` PNG screenshot names are intentionally reserved for reviewed Oracle training-tenant captures. Hide tenant URLs, user identities, notifications, credentials, and unrelated data.
