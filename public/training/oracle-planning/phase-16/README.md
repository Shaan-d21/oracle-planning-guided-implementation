# Phase 16 — Forms, Dashboards & Smart View practice pack

Use this pack to design and validate one role-based ApexPlan planner journey. Configure and capture only the authorized training tenant and workbook.

## Recommended exercise

1. Map each role to its tasks, decisions, artifacts, frequency, and handoffs.
2. Catalogue every form before configuration. Keep Plan1 input and detailed calculations separate from ApexPlan ASO reporting.
3. Build the production allocation form for Forecast / Working / FY25.
4. Enter 820 Pune and 560 Noida starts in 20-unit lots. Prove 1,380 total starts and 410 plus 280 required hours.
5. Launch the approved Phase 15 rule from the intended form context and connect the result to a job ID.
6. Reconcile the financial review form and management dashboard to the approved Phase 14 values.
7. Open the governed form in Smart View, refresh, submit only authorized level-zero inputs, refresh again, and reconcile with the web form.
8. Test role access, validation, suppression, first and repeated load, save, rule execution, dashboard filtering, Smart View, accessibility, and recovery.

## Completion standard

The workspace passes only when the intended role can complete the task correctly and efficiently, unauthorized edits and launches are blocked, calculated cells stay protected, rules inherit the approved context, dashboards reconcile to ApexPlan ASO, Smart View follows refresh-submit-refresh discipline, performance remains within thresholds, and evidence is retained.
