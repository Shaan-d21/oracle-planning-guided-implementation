# Phase 23 — Cutover practice pack

Use these templates to prepare and rehearse a controlled ApexPlan production cutover. Keep one version-controlled source of truth and retain links to Oracle job details, extracts, reconciliations, approvals, and communications as evidence.

## Files

- `cutover-runbook.csv` — dependency-driven execution, timing, evidence, and acceptance control.
- `reconciliation-control.csv` — source-to-Plan1-to-ApexPlan-ASO reconciliation.
- `rollback-plan.csv` — trigger, authority, recovery, validation, and continuity control.
- `communications-plan.csv` — audience-specific checkpoint and incident communications.

Replace sample dates, owners, files, thresholds, and evidence links with approved project values. Do not record credentials, secrets, or sensitive production data in the pack.
